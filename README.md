## 📋 Overview

Arc Raiders Enhancement Client is a powerful desktop tool designed to augment tactical shooter gameplay with real-time overlays and visual assistance. The application provides enhanced environmental awareness and target acquisition capabilities while maintaining optimal system performance.

---

## ✨ Key Features

- Real-time overlay with visual assistance
- Enhanced target tracking and acquisition
- Environmental awareness augmentation
- Optimized performance for tactical gameplay
- Customizable overlay settings
- Real-time threat detection and visualization
- Enhanced environmental awareness overlays
- Customizable visual indicators
- Adaptive display settings for different scenarios
- Low system resource usage
- Keyboard shortcut integration
- Profile-based settings management

---

## ⌨️ Keyboard Shortcuts

| Key Combination | Function |
|-----------------|----------|
| `INSERT` | Toggle overlay on/off |
| `F1` | Toggle visual assistance |
| `F2` | Cycle overlay themes |
| `F3` | Adjust transparency |
| `F4` | Reset overlay position |
| `F5` | Quick profile switch |
